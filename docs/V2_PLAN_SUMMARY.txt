--------------------------------------------------------------------------------
  3.  ARCHITECTURE EVOLUTION
--------------------------------------------------------------------------------

  The stack stays. The layering evolves. V1.0 put most logic in UI handlers;
  V2 introduces four new internal layers:

    services/     — owns all DB writes; emits audit events in same transaction
    clinical/     — pure-function rules engine (thresholds, grading, scheduling)
    reports/      — reportlab PDF + stdlib CSV generation
    migrations/   — numbered Python scripts with up()/down() per migration
    config/       — institution.yaml read via Pydantic at startup

  UI stays Tkinter but the monolithic dashboard window decomposes into panels
  (header, timeline, labs, cardiotoxicity, toxicity, alerts) so new features
  don't bloat a god-object. SQLite stays — audit_log table with JSON before/
  after fields is sufficient compliance plumbing for a single-user tool. No
  new top-level dependencies beyond reportlab (PDF) and pydantic (config
  validation).

  Principle: v1.0 was a dashboard; V2 is a dashboard backed by a clinical
  decision-support engine — the code layout should reflect that.

================================================================================
  SPRINT 6 — CARDIOTOXICITY SAFETY
================================================================================
  Duration:  10 days
  Points:    11
  Goal:      Every AC cycle's anthracycline dose tracked in mg/m²; cumulative
             dose visible; LVEF captured; nurse sees clear warning as patient
             approaches the threshold.

  US-023  BSA / height / weight per cycle (+ mini dose calculator)    (3 pts)
  US-024  Cumulative anthracycline dose calculation                   (3 pts)
  US-025  LVEF / cardiac assessment tracking                          (2 pts)
  US-026  Cardiotoxicity risk badge + cumulative-dose warning         (3 pts)

  Sequencing: US-023 → US-024 → US-026.  US-025 parallel to US-024.

  Key technical notes:
    - BSA default = Mosteller: sqrt(height_cm * weight_kg / 3600)
    - DuBois available via config.cardiotoxicity.bsa_formula
    - Warn on >10% weight change from prior measurement
    - Only doxorubicin tracked cumulatively in V2 (not cyclophosphamide)
    - Prior-anthracycline exposure field on patient demographics
    - Equivalence factors (dox 1.0, epi 0.5, dauno 0.5, ida 5.0, mito 4.0)
      read from config; NOT hardcoded
    - Badge states: green (<yellow threshold) / yellow / red / hard-stop
    - Red state = soft-block on AC cycle completion (override + reason audited)
    - Hard-stop (default 450 mg/m²) = hard-block; requires attending override

              (dose-density attribute); US-033 depends on Sprints 6+7 data.

  Key technical notes:
    - Expected cycle date = last_cycle_date + cadence_days (q3w=21, q2w=14)
    - Color coding: green on schedule / yellow due this week / red overdue
    - Pre-cycle checklist is THE most complex story in V2 — weaves every
      prior sprint's data through the rules engine:
         * ANC >= threshold (config, differs for AC vs T vs dose-dense)
         * Platelets >= 100k (config)
         * Labs drawn within 72h (config)
         * No active infection (nurse attestation)
         * Cumulative dose headroom >= next planned dose (AC only)
         * Neuropathy grade <= 1 (T only)
         * No active Grade >=3 symptoms
         * LVEF acceptable (AC only)
    - Each rule = one pure function in clinical/, independently unit-tested
    - Rule modes per config: advisory / soft-block / hard-block
    - Low-ANC banner: red <500, orange 500–999; dismissible per session

--------------------------------------------------------------------------------
  5.  INSTITUTIONAL CONFIGURATION LAYER
--------------------------------------------------------------------------------

  Every clinical threshold and rule reads from config/institution.yaml,
  validated via Pydantic at startup. Resolution order:

      hard-coded defaults  →  institution YAML  →  session overrides

  CONFIGURABLE:
    - All thresholds (ANC, platelets, cumulative dose, LVEF, lab freshness)
    - Anthracycline equivalence factors
    - BSA formula (Mosteller / DuBois)
    - Dose-modification tier set
    - Dose-density options enabled
    - G-CSF prophylaxis policy
    - CTCAE version (5.0 default; 4.03 for legacy sites)
    - Neuropathy grade → action mapping
    - Infusion reaction rechallenge policy
    - Symptom set (all-phases + T-phase additional)
    - Blocking mode per rule (advisory / soft_block / hard_block)
    - Pre-cycle checklist item selection
    - Backup reminder interval; daily worklist lookahead
    - Institution name, logo, PDF branding
    - Patient ID regex

  NOT CONFIGURABLE (by design):
    - CTCAE grade definitions (NCI-owned)
    - Audit logging behavior (always on)
    - Anything that would cause under-reporting of a safety signal
    - Schema-level data model (add via migration, not config)


--------------------------------------------------------------------------------
  6.  CLINICAL DEFAULTS (from published guidelines; configurable)
--------------------------------------------------------------------------------

  CARDIOTOXICITY
    Cumulative doxorubicin:   yellow 300 / red 400 / hard-stop 450 mg/m²
    Equivalence factors:      dox 1.0 | epi 0.5 | dauno 0.5 | ida 5.0 | mito 4.0
    LVEF absolute hold:       <50%
    LVEF delta hold:          drop >=10 points AND <55%
    LVEF review flag:         drop >=16 points
    LVEF cadence (AC-T):      baseline + end-of-AC

  PRE-CYCLE THRESHOLDS
    ANC (AC, T):              >=1500/uL
    ANC (dose-dense):         >=1000/uL from cycle 2
    Platelets:                >=100,000/uL
    Lab freshness:            <=72 h from draw to administration

  NEUROPATHY → ACTION
    Grade 0–1:                continue full dose
    Grade 2:                  hold 1 cycle, resume at -20%
    Grade 3:                  hold until <=Grade 1, resume at -25%;
                              discontinue on recurrence
    Grade 4:                  discontinue permanently

  INFUSION REACTION RECHALLENGE
    Grade 1:                  slow rate 50%, continue
    Grade 2:                  stop, rescue meds, restart 50%, enhance premeds
    Grade 3:                  do not rechallenge; switch to nab-paclitaxel/doce
    Grade 4 (anaphylaxis):    never rechallenge (hard-block)

  DOSE-MODIFICATION TIERS:   100% / 80% / 75% / 60% / 50% / 0%

  SYMPTOM QUICK-ENTRY
    All phases:               nausea, fatigue, mucositis, constipation
    T-phase additional:       arthralgia/myalgia, peripheral edema

  CTCAE version:              5.0

  G-CSF POLICY
    Dose-dense AC:            primary prophylaxis (pegfilgrastim every cycle)
    Standard AC:              primary only if FN risk factors; secondary otherwise

  BLOCKING MODES
    Hard-block:   cumulative dose >= hard-stop, Grade 4 reaction rechallenge
    Soft-block:   ANC/plt below threshold, Grade 3 neuropathy before T,
                  LVEF <50%, cumulative dose red
    Advisory:     Grade 2 neuropathy, Grade >=3 symptoms, labs >72h

--------------------------------------------------------------------------------
  8.  RISKS & MITIGATIONS
--------------------------------------------------------------------------------

  RISK:       Sprint 8 (pre-cycle checklist) is the largest cross-cutting
              story; it depends on every prior sprint's data model.
  MITIGATION: Build each rule as an independent pure function with its own
              tests before integration; rules can land incrementally.

  RISK:       Schema migration on a real user's v1.0 DB could fail mid-run.
  MITIGATION: Back up DB before every migration (US-017); wrap each
              migration in a transaction; ship a rollback test fixture.

  RISK:       Clinical thresholds hard-coded become painful to change
              mid-development or per-institution.
  MITIGATION: Config layer (US-017a) in Sprint 5. Every rule reads config.
              No magic numbers in code.

  RISK:       PDF layout churn during Sprint 9 could consume budget.
  MITIGATION: Ship oncologist template first (must); PCP + patient are
              stretch and can defer to V2.1 if needed.

  RISK:       Scope creep from "while you're in there" feature requests.
  MITIGATION: This document — Section 2 "Explicitly Out-of-Scope" is a
              refusal list. AC-TH, weekly paclitaxel, other regimens
              are V3, not V2.

  RISK:       Solo developer burnout on a 13-week project.
  MITIGATION: Sprint 10 explicitly labeled polish — resist adding stories.
              Ship V2 when it's done; V2.1 handles follow-up.
